INDEX VALUATION TRACKER - QUICK GITHUB SETUP
============================================

Repository name:
    index-valuation-tracker

Live site:
    https://projectdwister.github.io/index-valuation-tracker/

1. Upload/commit this repository with these paths preserved:
       .github/workflows/nifty-tracker.yml
       docs/

2. In GitHub open:
       Settings -> Pages
   Set:
       Source = GitHub Actions

3. Configure Gmail alert secrets in:
       Settings -> Secrets and variables -> Actions

   Required secrets:
       SMTP_USERNAME
       SMTP_PASSWORD
       ALERT_EMAIL_TO

4. Open:
       Actions -> Refresh Index Valuation Tracker and deploy Pages
   Click:
       Run workflow -> Run workflow

5. The weekday cloud refresh runs at 7:00 PM Asia/Kolkata.
   Your PC does not need to be on.

NOTES
-----
- The base website opens NIFTY 50.
- Only indices with useful historical depth are displayed.
- The top-right Excel button downloads the workbook for the selected index.
- Multi-index alerts are consolidated into one email per refresh when triggers occur.
- Update docs/data/nse_market_holidays.json when NSE publishes a new year's holiday calendar.

See README.md for the current methodology and full repository description.
